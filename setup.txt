============================================================
ACF (Allure) — GUIDE DE DÉMARRAGE
============================================================

Application web de course à intervalles.
Stack : Vite 7 + React 18 + TypeScript 5.9, tests Jest 30,
lint ESLint 9 (flat config), hébergement Firebase.

Tout le code de l'app est dans le dossier "web/".

------------------------------------------------------------
PRÉREQUIS
------------------------------------------------------------

- Node.js >= 20.19 (testé avec Node 22)
- npm (fourni avec Node)

------------------------------------------------------------
INSTALLATION
------------------------------------------------------------

> cd web
> npm install

------------------------------------------------------------
COMMANDES DE DÉVELOPPEMENT (depuis le dossier "web/")
------------------------------------------------------------

- Serveur de dev (hot reload) :
> npm run dev

- Build de production (tsc + vite build -> dossier "web/dist") :
> npm run build

- Prévisualiser le build de production localement :
> npm run preview

- Tests :
> npm test            # lance toute la suite Jest une fois
> npm run testw       # mode watch

- Lint :
> npm run lint        # ESLint 9 (flat config, voir eslint.config.js)

------------------------------------------------------------
DÉPLOIEMENT FIREBASE
------------------------------------------------------------

Projet Firebase : acf-allure (voir .firebaserc)
Hébergement : le contenu de "web/dist" est publié (voir firebase.json)
Règles de la base temps réel : database.rules.json

1. Installer l'outil (une seule fois) :
> npm install -g firebase-tools

2. Se connecter (une seule fois) :
> firebase login

3. Construire puis déployer (depuis la racine du dépôt) :
> cd web
> npm run build
> cd ..
> firebase deploy

------------------------------------------------------------
STRUCTURE DE L'OUTILLAGE
------------------------------------------------------------

- vite.config.ts        Configuration Vite (+ @vitejs/plugin-react)
- tsconfig.json         Configuration TypeScript (mode bundler, noEmit)
- eslint.config.js      Configuration ESLint « flat » (typescript-eslint,
                        react, react-hooks, react-refresh)
- jest.config.ts        Configuration Jest (ts-jest + jsdom)
- test/__ mocks __/     Mocks Jest pour les fichiers statiques

------------------------------------------------------------
NOTES / POINTS CONNUS (au 20/09/2026)
------------------------------------------------------------

- React est volontairement resté en version 18 (React 19, Vite 8,
  TypeScript 7 non appliqués pour éviter des changements cassants).

- typescript-eslint est passé de 6 à 8 : le linter est plus strict et
  remonte désormais des avertissements/erreurs sur du code existant
  (chaînage optionnel, template literals, namespace JSX déprécié, etc.).
  Beaucoup sont corrigeables avec « npx eslint . --fix ».

- Avis npm audit : uuid < 11.1.1 (modéré, buffer bounds sur v3/v5/v6 avec
  paramètre buf — non utilisé ici). Corrigeable en passant à uuid@14
  (changement cassant, ESM).
